# Outstanding verification tasks

Prioritised by the study sequence in [curriculum/dependencies.md](../curriculum/dependencies.md). **Study is not delayed by these**: each task
says what is already usable. "Student" means a task the student can do in minutes (usually a photograph of a contents page);
"web" means a task Claude Code can retry; "library" means a library copy or interlibrary loan is needed.
