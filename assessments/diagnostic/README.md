# Diagnostic assessment

**Not started.** The diagnostic is designed, set and assessed by ChatGPT as curriculum director and
academic assessor after Baseline v1 is approved. Claude Code does not write or mark it.

Store here, once it has been run:

- `YYYY-MM-DD-diagnostic-brief.md` - the problems set, with their syllabus item ids;
- `YYYY-MM-DD-diagnostic-responses.md` - the student's actual written work (transcribed or scanned),
  with the hints given for each problem;
- `YYYY-MM-DD-diagnostic-evaluation.md` - the assessor's evaluation and any Assessment Decisions.

The detailed personal study plan follows from the evaluation; see
[governance/assessment-standard.md](../../governance/assessment-standard.md) for how evidence is used.
